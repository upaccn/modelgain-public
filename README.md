# ModelGain

**AI inference optimization and remediation.**

ModelGain analyzes metadata-only LLM usage to find avoidable inference spend, explain root causes, recommend remediations, and verify realized savings without requiring prompt, completion, source-code, or provider-key custody by default.

The initial product is local-first and read-only. It is being developed for AI SaaS, agent, automation, support, research, translation, content, and data-processing workloads with metered model usage.

## Current focus

- version-aware inference cost analysis
- retry, cache, context-growth, and model-mix waste detection
- evidence-backed remediation recommendations
- before/after savings verification
- privacy-minimized telemetry workflows

Website: https://modelgain.com

This public repository is the project presence for ModelGain. Core development remains private during the current validation stage.
